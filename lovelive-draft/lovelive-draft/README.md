# ラブライブ！スクールアイドル ドラフト会議 — Web試作 v0.1.1

Node.js 20以上、外部npmパッケージ不要。

## 起動

```bash
npm start
```

`http://localhost:3000` を開いて「ルームを作成」。他の参加者は表示されたルームURLを開き、各自の球団名で参加する。インターネット越しで遊ぶ場合はこのNode.jsサーバーをHTTPS対応のホスティングにデプロイする。localhost のままでは別の端末からインターネット接続できない。

## 仕様

- 球団数2〜12、最大指名人数3/5/7/10、対象5グループをルーム作成時に選択。
- 作品ごとに学校名とキャラクター名を表示。初期候補合計50人。
- 第1巡：全チームが非公開入札 → ホストが参加順に1球団ずつ発表 → 競合者が指名順に未選択の封筒を選択して自ら開封 → 外れ球団は再入札。
- 2巡目以降：球団の入室順を基準とした交互ウェーバー。候補の二重指名はサーバーで防止。
- SSE同期。ルームコード＋ブラウザ内トークンによる再接続。
- 公開・抽選はサーバーで判定。抽選の当たり封筒は暗号学的乱数で決定。

## 制限・注意

- **試作版**。データはメモリ上に保持され、サーバーを再起動するとルーム・進行・指名結果は消える。永続DBは未実装。
- 対戦者の認証・不正アクセス対策・レート制限は未実装。公開サービス前には整備が必要。
- タイムアウト時の管理者代理指名や強制進行、ルーム上限・期限、観戦専用モード、投票アニメーション音声、指名スキップ、CSV書き出しは未実装。
- 「蓮ノ空」は104期9人で固定。対象世代の追加はデータ更新が必要。
- 球団名は参加時の任意入力。NPBや作品の画像・音声・ロゴは使わず、オリジナルの会議風デザインを使用。
- 非公式ファンメイドの試作であり、各権利者と無関係。
